support

Get herder running, and get help.

herder is free and open source. Help happens in the open, on GitHub.

Install

On a Linux machine (x86_64 or arm64) or an Apple silicon Mac:

$ curl -fsSL https://herder.sh/install | sh
  1. Run herder service install to run the daemon now and at every boot.
  2. Open the herder app on your Mac or iPhone, create your passkey and claim your machines. They join your Fleet.
  3. Add Account in the app, or n in the terminal UI (bare herder): the vendor's own login runs on the machine.
  4. Run herder doctor. It checks the machine and says how to fix anything that is not ready.
  5. herder update moves to the latest release.

The Mac app is on the releases page.

Report a bug or ask a question

Open an issue on GitHub. Say which version you run (herder --version), your OS, and paste what herder doctor prints. Leave out tokens, secrets and anything private: issues are public.

Contact

For anything you would rather not post in public, open an issue asking for a private channel.
